# 📝 Advanced Dark To-Do List App

A responsive, dark-themed To-Do List web application built using **HTML, CSS, and Vanilla JavaScript**.  
The app allows users to manage daily tasks with priorities, due dates, filters, and persistent storage using **LocalStorage**.

---

## 🚀 Features

- Add, edit, and delete tasks
- Mark tasks as completed or pending
- Task priority levels (Low, Medium, High)
- Due date support
- Filter tasks: All / Pending / Completed
- Clear all completed tasks
- Persistent data storage using browser LocalStorage
- Responsive UI (works on mobile & desktop)
- Modern dark UI with smooth interactions

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & responsiveness  
- **JavaScript (ES6)** – Logic & interactivity  
- **LocalStorage** – Data persistence  

No frameworks. No libraries. Just core web fundamentals.

## ⚙️ How It Works

- Tasks are stored as JavaScript objects
- All tasks are saved in `localStorage`, so data persists after page refresh
- Filters dynamically render tasks based on status
- Counts update automatically for pending and completed tasks
